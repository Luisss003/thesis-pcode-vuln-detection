# P-code Vulnerability Detection Thesis
This repo is for my master's thesis on binary vulnerability detection using Ghidra high P-code as an intermediate representation.

# Working Idea
The thesis investivates whether normalized Ghidra P-code can be used to detect vulnerable functions using a lightweight sequence model, such as BLSTM.

# Current Status
Idea has been proposed to two professors (Dr. Wei Wang and Dr. Zijie Zhang). Currently awaiting official thesis syllabus.

# Initial Goal
Build pipeline that can extract high P-code from compiled binaries, normalize, tokenize, and prepare for vulnerability classification.
